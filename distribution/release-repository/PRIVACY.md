# Privacy Notice

## アプリ内のデータ

How to Talkはローカルファーストで動作します。個人ナレッジ、設定、会話支援に
必要なワークスペースは端末内へ保存されます。生音声は保存せず、文字起こし、
要約、AI出力は既定で保存しません。

利用者が明示的にexportしたファイルは、利用者が選んだ保存先へ書き出されます。
共有前に内容を確認してください。

## 公開Issue

このリポジトリのIssue、コメント、添付ファイルは公開されます。次の情報を投稿
しないでください。

- 氏名、住所、電話番号、個人メールアドレス
- 実際の会話内容、録音、文字起こし
- API key、token、password、秘密鍵
- 端末のユーザー名や個人情報を含む絶対パス
- 本人または第三者を特定できるスクリーンショット

対応が必要と判断されたIssueは、アクセス制限された内部トラッカーへ内容を複製
する場合があります。公開Issueには内部トラッカーの情報を掲載しません。

誤って機密情報を投稿した場合は、Issueへの追記ではなくSecurity Policyの案内に
従ってください。
